## Паспорт

Собственный проект — серверная часть дневника питания. Он помогает сохранять приёмы пищи, считать КБЖУ и следить за целью снижения веса. Репозиторий: https://github.com/gonnem2/ProCaloryAI-backend.

Одна пользовательская роль — владелец личного дневника; до входа пользователь является гостем. Внешняя система для расширения — AI Core через Kafka и MinIO. Администратор объявлен в коде, но в объём работ не входит. Пять основных сущностей: User, MealLog, Goal, AnalysisRequest, Preferences. Настройки приватности — вспомогательные данные; Dish не используется текущей ORM.

Три основные функции: ручное ведение дневника, подсчёт статистики, установка цели. Фотоанализ запланирован и для запуска не требуется. Проект подходит под курс: есть своя предметная область, одна роль с внешними интеграциями и десять требований в работе 2.

Работа индивидуальная: Каменский Андрей Игоревич выполняет анализ, разработку и проверку. LICENSE сохраняет авторские права, открытая лицензия не объявляется.

Стек: Python 3.13.9, uv 0.9.5, FastAPI, Strawberry GraphQL, PostgreSQL 17.6, SQLAlchemy и Alembic. Версии Python-зависимостей закреплены uv.lock. Основной запуск: backend и PostgreSQL. Kafka и MinIO выделены в необязательный профиль photo; AI Core отсутствует.

## Запуск и проверка

Нужны Git, Docker Engine и Compose v2. После получения проекта запуск выполняется по README не более чем пятью командами. Команда docker compose up -d --build --wait собирает образ, создаёт новую БД, выполняет миграцию и ждёт готовности. Проверка: GET /health. Для ручных запросов открыть http://localhost:8000/graphql.

Сценарий из трёх шагов: зарегистрироваться; с access-токеном добавить «Овсяную кашу» с КБЖУ 250/8/5/42; запросить meals и todayStats. В чистом дневнике ожидаются новая запись и суммы 250/8/5/42.

Проверка 10.11.2026 выполнена автоматически на macOS в Linux-контейнерах с новой БД. Docker Engine 28.5.1, Compose 2.40.0-desktop.1. Проверены сборка, начальная миграция, health, 11 API-тестов и сохранение записи после перезапуска. Kafka, MinIO и AI Core не запускались. Проверка другим человеком ещё не проведена.

## Устройство и карта функций

| Часть | Назначение |
| --- | --- |
| src/main.py | Запуск FastAPI, GraphQL и health |
| src/api/graphql/ | Запросы, мутации и авторизация |
| src/application/service/ | Пользователь, дневник, статистика, цели и профиль |
| src/domain/models/ | Сущности предметной области |
| src/infrastructure/ | PostgreSQL, репозитории, транзакции; заготовки Kafka и S3 |
| src/migrations/ | Миграция структуры БД |
| tests/test_api.py | API-проверки на работающем приложении |

| Функции | Основной файл | Ручная проверка |
| --- | --- | --- |
| Регистрация, вход, refresh | service/user.py; mutations/auth.py | register → login → refreshTokens |
| Добавление, дневник, удаление | service/meal_log.py | addMealLog → meals → deleteMealLog |
| Итоги дня и недели | service/meal_log.py | todayStats и weeklyAverage |
| Цель и прогресс | service/goal.py | upsertGoal → goal |
| Предпочтения, профиль, показатели | service/profile.py | updatePreferences → preferences; me; achievements |
| Фотоанализ по плану | service/analysis.py | Сейчас возвращается сообщение, что Core не подключён |

Данные дневника хранятся в PostgreSQL в именованном Docker-томе. Конфигурация передаётся переменными окружения из Compose и .env. Пароли и токены в отчёт не включаются. Старые каталоги postgres_data и minio_data не используются новым запуском и не изменяются.
