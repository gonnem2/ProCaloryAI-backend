# План показа первой лабораторной

## Что за проект

ProCaloryAI — сервер личного дневника питания. Сейчас можно зарегистрироваться, добавлять еду вручную, смотреть статистику и задавать цель. Анализ фотографий требует внешнего Core и пока отложен.

## Показ запуска

1. В терминале выполнить docker compose up -d --build --wait.
2. Открыть http://localhost:8000/health — status и database должны быть ok.
3. Открыть http://localhost:8000/graphql.

## Основной сценарий

Запросы лежат в scripts/smoke.graphql. Выполнять по одной операции.

1. register — создать аккаунт с новой почтой, получить accessToken.
2. В Headers задать Authorization: Bearer <accessToken>.
3. addMealLog — добавить «Овсяную кашу» с КБЖУ 250/8/5/42.
4. meals и todayStats — показать сохранённую запись и суммы.
5. При необходимости показать me, preferences и goal.

Быстрая автоматическая проверка: docker compose exec -T backend python - < scripts/smoke.py.

## Короткие ответы

- Данные хранятся в PostgreSQL, миграция применяется автоматически.
- Пароль хранится как bcrypt-хеш, авторизация использует JWT.
- Есть только backend; GraphQL IDE служит для проверки API.
- Kafka и MinIO оставлены для будущего фотоанализа, Core для запуска не нужен.
- Требования второй работы заполнены, работы 3–6 пока являются заготовками.
